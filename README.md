# Manga Library Server - web scraping microservice
Esta API de python esta diseñada como microservicio para hacer web scraping a sitios cuyo contenido es manga/manhua/manhwa.

## Tecnologias

* Python
* FastAPI
* pydantic
* os
* BeautifulSoup
* httpx
